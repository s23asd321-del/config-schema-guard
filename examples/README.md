# Examples

This directory contains local-only example schemas and configs.

- `schema/basic.schema.json`: basic v1 schema.
- `good-config/config.json`: JSON config expected to pass.
- `good-config/config.toml`: TOML config expected to pass.
- `bad-config/config.json`: JSON config expected to fail validation.
- `bad-config/config.toml`: TOML config expected to fail validation.

Sensitive-looking values are fake placeholders only. Do not replace them with real secrets in committed examples.
