# AGENTS.md

This project is a local configuration validation CLI tool.

Agent and maintainer guidance:

- Do not connect to the network by default.
- Do not upload user configuration files.
- Do not collect telemetry.
- Do not execute configuration file contents.
- Do not use `eval`.
- Do not output real sensitive field values.
- Do not add real tokens, passwords, cookies, API keys, proxy subscription links, or credentials.
- Do not add illegal, abusive, attack, evasion, cracking, piracy, or misuse-related content.
- Add tests for every new validation rule.
- Update README or docs when user-visible behavior changes.
- Keep security, privacy, and legal wording conservative.
- Avoid unnecessary dependencies.
- Do not implement network features, AI features, databases, Web UI, or a plugin system in the first version.
